# 첨부파일 본문 추출 방식

## 목적

첨부파일을 색인하기 전에 어떤 파일을 대상으로 어떤 방식으로 본문을 추출할지 기준을 정의한다.

## 1차 지원 범위

- `pdf`
- `docx`
- `pptx`
- `xlsx`
- `csv`
- `txt`
- `md`
- `hwp`
- `hwpx`

## 추출 기준

- `pdf`는 텍스트 레이어가 있는 파일을 우선 지원한다.
- `docx`, `pptx`, `xlsx`, `csv`, `txt`, `md`는 텍스트 추출 가능한 범위에서 본문을 추출한다.
- `hwp`, `hwpx`는 추출 가능한 범위에서 우선 지원한다.
- 추출된 본문은 기존 색인 파이프라인의 `content`로 전달하는 것을 기준으로 한다.

## 제외 또는 실패 처리 대상

- 스캔 PDF
- 이미지 기반 문서
- 암호화된 파일
- 본문 추출이 불가능한 파일

위 파일은 이번 범위에서 제외하거나 추출 실패 상태로 처리한다.

## 색인 전달 기준

- 파일명, 확장자, 파일 타입, 원본 문서 정보는 metadata로 함께 전달한다.
- 본문 추출 결과는 별도 구조를 만들지 않고 색인 요청의 본문 필드로 전달한다.
- 추출 실패 파일은 무시하지 않고 실패 상태를 남긴다.

## 구현 우선순위

1. `pdf`, `docx`, `pptx`, `xlsx`, `csv`, `txt`, `md`
2. `hwp`, `hwpx`
3. 추출 실패 처리 규칙 정리
4. 색인 payload 연동
